DEEP DIVE TEKNOLOGI

Keunggulan Kuantitatif Kelas Institusi

Kombinasi model AI Time-Series terbaru dari Google Research dan transparansi data bursa berjangka Amerika Serikat.

🧠 Google Research TimesFM vs Indikator Konvensional

Indikator klasik (RSI, MACD) bersifat tertinggal (*lagging*). TimesFM adalah *decoder-only foundation model* yang memproyeksikan lintasan harga ke depan dengan interval ketidakpastian matematis.

Dimensi Indikator Klasik (RSI/MA) Google Research TimesFM
Tipe Analisis Historis & Reaktif (Melihat ke belakang) Prediktif & Probabilistik (Melihat ke depan)
Penentuan Stop Loss Statis (Asal tebak misal minus 2%) Dinamis Berbasis Statistik (Quantile P10)
Korelasi Makro Terbatas pada 1 grafik harga Mendukung Kovariat (DXY, Yield, Volume)

Membaca posisi uang miliaran dollar institusi hedge fund pada kontrak berjangka di bursa New York/Chicago dan menerjemahkannya ke saham emiten Indonesia:

Instrumen CFTC COT Kategori Institusi Utama Saham Terkait di IDX (Bursa Efek Indonesia)

Crude Oil WTI (NYMEX) Oil Producers vs Hedge Funds MEDC, ENRG, PGAS, RAJA

STANDAR KEAMANAN KREDENSIAL MUTLAK

Zero-Exposure Rule

Sistem ini dirancang dengan prinsip keamanan data paling ketat untuk melindungi akun finansial dan aset pengguna:

  • 🔒 Kunci API & rahasia tersimpan ketat di .env lokal. TIDAK PERNAH dikirim ke frontend atau context LLM publik.
  • 🌐 Sesi browser web broker menggunakan mode Chrome Remote Debugging. Anda login manual, agent hanya membaca WebSocket tanpa melihat password.
  • ✋ Semua eksekusi live mewajibkan izin persetujuan eksplisit pengguna via Terminal, Web, atau Telegram (Human-in-the-Loop).
